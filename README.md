# Interior Design Style Classification

A deep learning-based computer vision project for classifying indoor room images into **17 different interior design styles**. The project explores image preprocessing, data analysis, transfer learning, and deep learning techniques to identify visual patterns such as furniture, color schemes, textures, decorations, and room layouts.

### 🎨 Design Styles

The model classifies images into the following categories:

**Asian, Boho, Coastal, Contemporary, Craftsman, Eclectic, Farmhouse, French Country, Industrial, Mediterranean, Minimalist, Modern, Scandinavian, Shabby Chic, Southwestern, Tropical, and Victorian.**

### 🚀 Project Goal

The main objective is to build a reliable multi-class image classification system capable of recognizing interior design styles from unseen room images. The project covers the complete machine learning workflow, from dataset exploration and preprocessing to model training, evaluation, and prediction.

### 📊 Task

**Type:** Multi-class image classification
**Number of Classes:** 17
**Input:** Indoor room images
**Output:** Predicted interior design style

This repository contains the implementation, experiments, and evaluation of deep learning models developed for automated interior design style recognition.
